# Branching Strategy

## Branches

- `main`: stable production-ready branch.
- `develop`: integration branch.
- `feature/*`: new features.
- `fix/*`: bug fixes.
- `test/*`: test-only work.
- `docs/*`: documentation.
- `refactor/*`: refactoring.

## Commits

Use Conventional Commits:

- `feat:`
- `fix:`
- `docs:`
- `test:`
- `refactor:`
- `chore:`
- `ci:`

Every important feature should be linked to a GitHub Issue and delivered through a Pull Request.
