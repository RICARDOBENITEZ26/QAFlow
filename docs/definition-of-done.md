# Definition of Done

A task is done when:

- Acceptance criteria are met.
- TypeScript strict mode remains enabled.
- No unjustified `any` is introduced.
- Validation and authorization are added where relevant.
- Errors are handled safely.
- Tests match the risk of the change.
- Formatting, linting, typecheck, tests, and build pass.
- Documentation is updated when behavior, setup, API, or architecture changes.
- No secrets are committed.
- PR notes include test evidence.
