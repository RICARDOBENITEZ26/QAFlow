# Product Requirements Document

## Vision

QAFlow is a SaaS platform for managing software quality workflows across requirements, test cases, execution, defects, evidence, and reporting.

## Problem

QA teams often manage quality artifacts in disconnected spreadsheets, messages, screenshots, and issue trackers. QAFlow centralizes those artifacts so teams can understand coverage, execution status, and product risk.

## Target Users

- Admin
- QA Lead
- QA Engineer
- Developer
- Viewer

## MVP Scope

- Authentication and roles.
- Organizations and projects.
- Requirements.
- Test suites and test cases.
- Manual test runs.
- Bugs from failed executions.
- Evidence metadata.
- Basic reports and dashboards.

## Out of Scope

- Billing.
- AI generation.
- Real-time collaboration.
- Native Jira/GitHub integrations.
- Mobile native apps.
